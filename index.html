About Me

I am a passionate Full-Stack Developer with a strong foundation in building responsive, user-centered web applications from concept to deployment. I specialize in turning complex problems into clean, efficient, and scalable solutions using modern web technologies.

On the front end, I work extensively with HTML5, CSS3, JavaScript, and Bootstrap, focusing on accessibility, responsive design, performance optimization, and intuitive user experience. I enjoy creating modern interfaces that are visually appealing, mobile-friendly, and easy to navigate.

On the back end, I specialize in building robust server-side applications using Node.js and Express.js. I develop RESTful APIs, handle authentication and authorization, manage server routing, and ensure secure communication between client and server. I also work with databases such as MongoDB to design, store, and manage scalable application data efficiently.

In addition, I have experience with Git and GitHub version control, deployment workflows, debugging, and application optimization.
